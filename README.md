> Every advertised feature must have a real implementation.

---

## Architecture (Owner Decision)

| Layer                    | Technology                          | Notes |
|--------------------------|-------------------------------------|-------|
| Application Shell        | Capacitor 6                         | Hybrid |
| UI / Timeline / Preview  | HTML5 + CSS3 + Vanilla JS (ES modules) | Lowest RAM, full touch control |
| Video Processing / Export| Android Media3 Transformer (native) | Primary engine – trim, merge, effects, composition |
| Preview                  | HTML5 Video + Canvas + proxy files  | Never load full resolution into JS |
| Image Editing            | Canvas API + native helpers         | |
| AI Tools                 | Pluggable external APIs + fallbacks | Never fake success |
| Storage                  | Capacitor Filesystem + MediaStore   | Scoped storage |
| Audio                    | Media3 + Web Audio API (preview)    | Multi-track |

**Hard rules**
- No FFmpeg.wasm for large videos.
- Proxy previews (≤480p) generated on import.
- All heavy work happens natively.
- AI operations report real success/failure only.

## How to Build & Run (Android)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Add Android platform (first time):
   ```bash
   npx cap add android
   ```

3. Sync web assets:
   ```bash
   npx cap sync android
   ```

4. Open in Android Studio:
   ```bash
   npx cap open android
   ```

5. Build APK:
   - Android Studio → Build → Build Bundle(s) / APK(s) → Build APK(s)
   - Or `./gradlew assembleDebug` inside `android/`

**Required native work (Phase 2+)**  
You must implement a custom Capacitor plugin that wraps Media3 Transformer.  
See `docs/PHASES.md` for the exact API contract.
